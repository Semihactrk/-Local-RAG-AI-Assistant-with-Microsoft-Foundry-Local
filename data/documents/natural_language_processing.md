What Is Natural Language Processing

Natural Language Processing (NLP) sits at the intersection of linguistics,
computer science, and machine learning. It lets computers process, analyze,
and generate human language in a structured way, decoding meaning,
context, and intent from spoken or written text rather than just
recognizing individual words.

Common NLP Tasks

Typical NLP tasks include text classification, spam filtering, sentiment
analysis, summarization, question answering, information extraction, and
machine translation. These tasks power everyday tools such as search
engines, translation systems, chatbots, help-desk assistants, and writing
copilots across many industries.

The Role of Transformers

Transformer-based large language models, such as BERT, GPT, and T5, are
now central to modern NLP because they can handle long documents, follow
instructions, and generate fluent text. Their main drawback is that the
self-attention mechanism at their core is computationally expensive, which
is why newer research focuses on more efficient attention mechanisms and
on-device NLP for smaller, faster models.

How NLP Relates to This Project

The Retrieval-Augmented Generation (RAG) pipeline in this project is
itself an NLP application: it combines an embedding model (semantic text
understanding) with a chat model (text generation) to answer questions
grounded in a specific document set.
