What Is Foundry Local

Foundry Local is an end-to-end local AI solution developed by Microsoft
that lets large language models (LLMs) run entirely on a user's own
device. It provides a lightweight runtime and SDK; no cloud account or GPU
is required. It automatically downloads and manages models, and delivers
local, offline AI with zero network calls by automatically using
CPU/GPU/NPU acceleration.

What Is RAG (Retrieval-Augmented Generation)

RAG is an AI design pattern: relevant information is first RETRIEVED from a
document set, that information is then AUGMENTED into the model's input
prompt, and finally the model GENERATES an answer using that context. This
means the model's answers are grounded in your own data, hallucination is
reduced, and source citation becomes possible.

Advantages of SQLite

SQLite is a serverless, self-contained SQL database engine made up of a
single file. It is the most widely used database engine in the world. Not
requiring a separate server setup, being cross-platform, and being easy to
integrate make it ideal for local data storage.

Embeddings and Vector Search

An embedding is a way of representing the meaning of a piece of text as a
numeric vector. Texts that are similar in meaning are positioned close to
each other in vector space. This property makes semantic search possible:
a query is embedded, cosine similarity is computed against every chunk
embedding in the database, and the highest-scoring chunks are considered
"most relevant."
